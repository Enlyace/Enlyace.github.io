# 保姆工资计算器

这是一个本地网页小工具，用来按日期计算保姆的应付工资。

## 计算规则

- 默认基准规则：`26` 天工资 `7000` 元
- 日工资 = 基准工资 ÷ 基准天数
- 工作天数 = 结算区间总天数 - 休息天数
- 应付工资 = 工作天数 × 日工资

## 使用方法

1. 直接双击打开 [index.html](./index.html)
2. 输入开始日期和结束日期
3. 在“休息日期”里填写休息的天数
4. 点击“计算工资”

## 休息日期支持格式

- 单个日期：`2026-01-10`
- 中文日期：`1月10日`
- 连续简写：`1月10日，11号，12号`
- 日期区间：`2026-01-20 ~ 2026-01-22`
- 多个日期：每行一个，或同一行用逗号分开

## 示例

如果：

- 结算区间是 `2026-01-01` 到 `2026-01-31`
- 休息日期是 `1月10日`、`1月11日`、`1月12日`

那么：

- 总天数 = `31`
- 休息天数 = `3`
- 工作天数 = `28`
- 日工资 = `7000 ÷ 26 = 269.23`
- 应付工资约为 `7538.46` 元
